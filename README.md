# Zotero 内 Codex 伴读

一个面向 Zotero 的本机伴读插件：在 Zotero 侧边打开聊天窗口，把当前 PDF 页面的文字和截图发送给已登录的 Codex 会话。

## 项目状态与适用范围

这是一个个人实验性质的本机集成项目，不是官方 Zotero 或 OpenAI 插件。它依赖本机已安装并已登录的 Codex，以及 Zotero 10 的插件接口；不同版本可能需要调整代码。使用前请阅读安全说明，并自行检查代码。

构建时通过环境变量 `CODEX_ZOTERO_THREAD_ID` 指定一个已有的 Codex 会话。插件不会创建或分叉会话，不调用 AI4Paper 服务。使用本机 Codex 已有的 ChatGPT 登录；模型的可用性与用量由该账户决定。

## 安装与打开

先设置 `CODEX_ZOTERO_THREAD_ID`，再运行 `python build.py` 生成 XPI；在 Zotero 的“工具 → 插件”页面选择“从文件安装”该 XPI。这是本机制作的插件，不要将包含 runtime.json 的目录分享给他人。

0.1.3 在构建时注入非敏感本机路径，避免 Zotero 10 的旧 URI 读取接口在启动时抛出 nsIURI.username 错误。

0.1.2 补齐 Zotero 安装器要求的 HTTPS `applications.zotero.update_url`。地址为本机预留的 `https://127.0.0.1:23126/updates.json`，此版本没有自动更新服务器，须手动安装新 XPI；手动检查更新会提示无法连接，不影响聊天。它不会访问第三方更新服务，也不放宽 Zotero 的更新安全检查。0.1.0 缺少字段而被判为无效安装包；0.1.1 的 HTTP 地址会被更新安全规则禁用，请使用 0.1.2。

安装后，在“工具 → Codex 伴读（当前会话）”打开 Zotero 所属的聊天窗口。右侧条目/阅读内容栏也会增加 Codex 伴读分区。选中文字后，划词弹窗会增加“问 Codex”。

## 同一会话的接管限制

Codex 对已有会话实施单写者限制。如果提示“正在 Codex 桌面端使用”，请先保存工作并完全退出 Codex 桌面应用，再在 Zotero 伴读中点击“连接当前会话”。仅停止回答、最小化窗口或切换标签可能不会释放写入者锁。

本插件不会关闭 Codex、删除会话锁，也不会在失败时偷偷另开一个对话。聊天由本机 app-server 处理；桌面应用提供的动态工具不保证在本客户端可用。遇到需要授权或外部工具的交互，插件会提示回到桌面端处理。

## 阅读上下文

发送问题时，勾选“随问题附带当前页文字和图片”将尝试读取当前 PDF 页面。页面区域按可见面积选取；多页并排时可能需在问题中明确图号。选中文字可通过“问 Codex”保留。若 PDF 画布无法导出，界面明确显示未附图片，不会声称模型已经看到了图。

## 本地服务

插件启动 `pythonw.exe bridge.py --config runtime.json`，仅监听 `127.0.0.1:23125`。每次请求验证本地随机令牌与 Host/Origin；不向局域网开放，不提供网页跨域接口。无模型 API Key 存入插件。

返回 Codex 桌面端前，点击“断开并释放会话”，本地桥接进程将在确认 app-server 已退出后回复。插件禁用或 Zotero 退出时也会请求关闭服务；如果软件突然退出，90 秒没有已认证客户端请求后会自动关闭本机桥接和 app-server。不要手动删除 Codex 会话锁。

请求超时时会保留“结果尚未确认”状态并阻止重复发送，直到收到同一轮的完成通知或手动断开。

验证命令：`python -m unittest discover -s zotero-chat -p test_bridge.py -v`。

目前已经验证：官方 JSON-RPC 初始化、当前会话只读查询、ChatGPT 账户类型识别、活动写入者锁错误，以及关闭桌面应用后的会话交接、文本提问、当前页截图附带和模型回答。
